## Summary

Every CLI command shown in the repo's documentation now matches a command verified to run in a fresh venv; the
impossible `python -m tessera_seal.cli` form is gone from all live docs. tessera-hash finally has a project
README at parity with its siblings. Each project gained runnable Go examples plus Python→Go interop pipes, all
executed by a new `run-examples.sh` gate. A new `check-md-links.sh` gate verifies every relative markdown link
repo-wide (23 broken links found and fixed). TesseraSeal adopters get a documented safe chunking pattern for
large files.
