# 2026-06-15 — TESS-00025 — Logo set for tessera + the three formats

**Type:** `docs(TESS-00025)` · **Scope:** new `assets/logo/` SVG set; README headers (root + 3 projects). No code, no wire, no normative change.

## Summary

The project had no visual identity. This adds a flat **SVG** logo set — one for the umbrella and one
for each format — sharing a single visual system: a rounded *tessera* (mosaic tile) carrying a
per-format glyph. The name is Latin/Greek for a mosaic tile (root sense "four"): small independent
pieces that compose into a whole — the project's architecture, and a nod to the lattice motif of
post-quantum cryptography. SVG was chosen over raster so the marks are scalable and text-diffable
(no binary blobs in a spec-first repo).

## Code changes

- `assets/logo/tessera.svg` — umbrella: a 2×2 mosaic = the three format glyphs (sorted records / `#` /
  padlock) + a dark **keystone** tile ("tiles within a tile") for the shared core. The front-door mark.
- `assets/logo/tessera-id.svg` — sorted records (identity, time-sortable), blue `#2563EB`.
- `assets/logo/tessera-hash.svg` — hash `#` (content integrity), teal `#0D9488`.
- `assets/logo/tessera-seal.svg` — padlock + keyhole (confidentiality), violet `#7C3AED`.
- `assets/logo/README.md` — concept, palette (ink `#0F172A`, paper `#F8FAFC`), file table, and the
  `rsvg-convert` / `inkscape` commands to rasterize to PNG.
- README headers: umbrella logo centered atop the root `README.md`; each format's logo left-aligned
  atop `tessera-id/README.md`, `tessera-hash/README.md`, `tessera-seal/README.md`.

## Wire/API changes

None. Pure branding assets + README presentation.

## Migration guidance

None. To produce a PNG (e.g. for a social card or favicon):
`rsvg-convert -w 512 -h 512 assets/logo/tessera.svg -o tessera-512.png`.

## Test plan

- Each SVG rendered with `rsvg-convert -w 256` and visually verified: glyphs legible, colors correct,
  umbrella reads as the three formats + keystone.
- All four are valid standalone SVG (1 `<svg>` root, 128×128 viewBox, no scripts) so GitHub renders
  them via `<img src>` in Markdown.
