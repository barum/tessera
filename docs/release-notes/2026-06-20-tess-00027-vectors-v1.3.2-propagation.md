# 2026-06-20 — TESS-00027/00028/00029/00030 — tessera-vectors v1.3.2 propagation + mirror tooling fixes

**Type:** `chore(TESS-00027)` (vectors v1.3.2 propagation) + `fix(TESS-00028)` (mirror generator Java
Makefile) + `fix(TESS-00029)` (freeze-gate ROOT) + `fix(TESS-00030)` (cpp mirror gitignore).
**Scope:** hub `tools/mirror/`, the shared `tessera-vectors` repo, and all 8 language mirror repos.
**Operator impact:** mirror repos advance to `tessera-vectors v1.3.2`; no wire/algorithm change.

## Summary

The hub commit c55fb19 (TSEAL-00050) appended `kyberslash_regression.json` to the seal conformance
vectors but it had not propagated: `tessera-vectors` was still v1.3.1 and all 8 mirrors pinned the v1.3.1
submodule, so no mirror carried (or exercised) the new KyberSlash KAT. This change propagates it
end-to-end and fixes three tooling defects found along the way.

## What shipped

1. **tessera-vectors v1.3.2** (`chore(TSEAL-00050)`, commit 1fd3b9c, tag `v1.3.2`): append
   `vectors/tessera-seal/kyberslash_regression.json` (byte-identical to the hub), `VERSION` 1.3.1→1.3.2,
   `SOURCE hub_sha → c55fb19`, README seal count 9→10 files / 67→68 records. Append-only freeze contract
   verified (no existing record mutated).
2. **Mirror generator bump** (`chore(TESS-00027)`, hub c35aa0e): `tools/mirror/sync-mirrors.sh`
   `VECTORS_TAG` v1.3.1 → v1.3.2 so regenerated mirrors pin the new vectors.
3. **All 8 mirrors refreshed**: `_vectors` submodule → v1.3.2 (1fd3b9c), `SOURCE hub_sha` → current hub
   HEAD. The four glob-seal mirrors (c/go/python/rust) bump `conformance/replay.sh` `EXPECT_PASS`
   297→298 (the seal runner now exercises the KyberSlash record as a real PASS). The four runner-less
   mirrors (cpp/ts/java/cpython) carry the vector and exercise it via a new in-suite KAT case
   (see `tessera-seal/docs/release-notes/2026-06-20-tseal-00050-...md`).
4. **Mirror generator Java Makefile fix** (`fix(TESS-00028)`, hub 3af8581): the generator never staged
   `tools/conformance/java`, so the materialized `conformance/Makefile` kept the hub-relative
   `REPO_ROOT=../../..` (escaping the repo) and `COMMON_SRC=$(REPO_ROOT)/common/java` (nonexistent —
   Keccak is vendored into tessera-hash). Now staged + repathed (`REPO_ROOT=..`,
   `COMMON_SRC=$(REPO_ROOT)/tessera-hash/java/src/main/java`), matching the C/C++ case. The materialized
   `tessera-java/conformance/Makefile` is fixed in lockstep.
5. **Freeze-gate ROOT fix** (`fix(TESS-00029)`, tessera-vectors cc5ea29): `tessera-vectors/check-vector-freeze.sh`
   computed `ROOT=$(dirname)/../..`, two levels ABOVE the repo, so `git ls-files vectors/*/*.json` matched
   nothing and the append-only gate silently passed as a no-op. Dropped the `/../..`; the gate now checks
   all 27 vector files and fails (exit 1) on a mutated record.
6. **cpp mirror gitignore fix** (`fix(TESS-00030)`): the cpp mirror's `.gitignore` `*/cpp/test_*` matched
   both the compiled binary AND the source `test_tessera_seal.cpp`, so the cpp mirror shipped no seal
   test at all (unlike ts/java/cpython). Narrowed to ignore only the binary; the source seal test (now
   with the KyberSlash KAT) is tracked.
