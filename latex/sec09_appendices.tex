\section{Author and Document Provenance}
\label{sec:appendix-provenance}

\textbf{Author:} Bahram Samani, \tessera{} monorepo maintainer.

This umbrella whitepaper is built from LaTeX sources under \texttt{latex/} (\texttt{main.tex} + \texttt{secNN\_*.tex}); the build chain is \texttt{pdflatex $\rightarrow$ bibtex $\rightarrow$ pdflatex $\times$ 2} per the Makefile. The artifact at the repo root \texttt{Tessera\_Whitepaper.pdf} is regenerated and committed alongside any normative change to the umbrella.

\textbf{Per-project documents.} This umbrella does not restate normative content from the per-project whitepapers. Refer to:

\begin{itemize}
\item \tesseraid{}: \texttt{tessera-id/latex/TesseraID\_Whitepaper.pdf} (repo root: \texttt{TesseraID\_Whitepaper.pdf}). 46-page document covering wire format, security analysis, distributed-systems model, comparisons with UUIDv4/v7/ULID/KSUID/Snowflake, eight-language reference implementations.
\item \tesserahash{}: \texttt{tessera-hash/latex/TesseraHash\_Whitepaper.pdf} (repo root: \texttt{TesseraHash\_Whitepaper.pdf}). 21-page document covering wire format, SHAKE-256 binding, encodings, security argument, conformance, comparison with adjacent hash formats.
\item \tesseraseal{}: \texttt{tessera-seal/latex/TesseraSeal\_Whitepaper.pdf} (repo root: \texttt{TesseraSeal\_Whitepaper.pdf}). 26-page document covering wire format, ML-KEM-1024 binding, hybrid suite \code{0x06}, AEAD + UtC commitment, KDF, AD-binding patterns, failure modes, side channels, plugin protocol, conformance, comparisons.
\end{itemize}

\textbf{Authority order} (when sources disagree): the per-project whitepaper for project-specific content; this umbrella whitepaper for cross-project content; then the per-project Python reference; then the per-project canonical C ABI; then every other language port. A cross-language disagreement is never resolved by changing the spec to match an outlier.

\textbf{Conformance gate}: \texttt{tools/conformance/run.sh} is the branch-protection check on \texttt{main}. Latest cross-language run (2026-05-21, alpha quick loop): 1051 PASS, 0 FAIL across all three projects on the four alpha languages.

The OpenSSL, RustCrypto, Go core team, \texttt{kyber-py}, SunJCE, and \texttt{@noble} maintainers for the cryptographic primitive sources \tesseraseal{} vendors. The Cryspen team for \texttt{mlkem-native} (retained as embedded-target fallback). The X-Wing draft authors \citep{xwing-draft} for the combiner design idiom \tesseraseal{}'s hybrid suite borrows. The KyberSlash, PQShield, and GoFetch disclosure teams, whose findings shape \tesseraseal{}'s side-channel disclaimer.
