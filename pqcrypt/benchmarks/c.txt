PQCrypt C benchmarks (OpenSSL 3.5+ ML-KEM-1024 + AES-256-GCM)
----------------------------------------------------------------------
Run on:    Apple M4 Max, clang/Apple LLVM, OpenSSL 3.5 (Homebrew), v1.2
Date:      2026-05-21
Harness:   pqcrypt/c/bench_pqcrypt.c (custom clock_gettime CLOCK_MONOTONIC,
           3 iterations, best-of-3 reported; matches Rust harness pattern).
Build:     cd pqcrypt/c && make bench
Note:      OpenSSL 3.5+ native EVP_KEM ML-KEM-1024. AES-256-GCM uses
           ARMv8-A AES instructions on Apple Silicon. Decrypt cost dominated
           by ML-KEM Decaps; encrypt benefits from cached Encaps path.
           v1.2 hybrid (suite 0x06) is Python-only in this release.
