PQCrypt Python benchmarks (canonical reference, pqcrypt.py)
----------------------------------------------------------------------
Run on:    Apple M3 Max, Python 3.14.3, kyber-py 1.0, cryptography 46.0.5
Date:      2026-05-21 (v1.2 refresh)
Note:      Pure-Python kyber-py ML-KEM-1024 dominates the time budget.
           C/Go/Rust ports are ~100x faster at keygen/encrypt/decrypt.
           Hybrid (0x06) ~10% slower than non-hybrid: extra X25519 keygen +
           ECDH per envelope, plus 32-byte SHAKE-256 combiner output.
           peek_header (no crypto) reflects the wire-parser baseline.
