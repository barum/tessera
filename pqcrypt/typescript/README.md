# pqcrypt/typescript

TypeScript reference implementation of PQCrypt v1.

**Status:** v1.1 placeholder.

Authoritative spec: [../latex/](../latex/) and the built `../latex/PQCrypt_Whitepaper.pdf`.

Dependencies (planned): [`@noble/post-quantum`](https://github.com/paulmillr/noble-post-quantum) v0.4+ for ML-KEM-1024, `@noble/ciphers` for AES-256-GCM + ChaCha20-Poly1305, `@noble/hashes` for SHAKE-256 / HMAC-SHA3-256.
